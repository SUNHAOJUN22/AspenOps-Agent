# Native AI scientific illustrations

Each PNG is an intact native output of the image generation tool. No SVG/HTML rendering or post-generation text compositing was used. The images are conceptual illustrations; exact equations, units, implementation mappings and limits are documented in the repository README.

The four current assets are `architecture.png`, `algorithm.png`, `roadmap.png` and `seven-repo-roadmap.png`. The shared overview shows proposed scientific handoffs among independent repositories.

`manifest.json` binds each final PNG to its SHA-256, size, pixel dimensions and original output identifier. `prompts.json` retains the generation/edit prompts; individual provenance records also bind any edited input. The provider did not expose a model identifier or certified generation timestamp; those are not invented. The recorded UTC date identifies this generation session.
